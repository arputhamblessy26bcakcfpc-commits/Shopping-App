🛍️ ShopEase – Shopping Cart Flow

## 📌 1. Project Overview

ShopEase is a modern e-commerce mobile application UI/UX project designed to create a simple and smooth online shopping experience.

The project focuses mainly on the shopping cart and checkout journey, starting from browsing products and continuing through product selection, adding items to the cart, checkout, order review, and order confirmation.

Main User Flow

Browse Products → Product Details → Add to Cart → View Cart → Checkout → Review Order → Order Placed

The prototype demonstrates how users can move between different screens through interactive buttons and navigation. Figma prototypes can be used to explore user journeys and test interactions between screens.

## 🎯 5. UX Features

The UX is designed around simplicity, clarity and minimum steps.

Clear User Flow

The journey is easy to understand:

Home → Product → Cart → Checkout → Review → Confirmation

Visual Feedback

The “Added to Cart!” screen immediately tells the user that the action was successful.

Easy Navigation

Back arrows, bottom navigation and clearly labelled buttons make navigation easier.

Quantity Control

Users can easily increase or decrease the number of products directly from the cart.

Error Prevention

The review screen allows users to check their products and total amount before placing the order.

Checkout Progress

The Address → Payment → Review indicator shows users where they are in the checkout process.

Consistent Interaction

Buttons and navigation elements behave consistently across screens. Interactive components and variants can also be used in Figma to maintain consistent behaviour.

## ✨ 6. Design Highlights

**🎨 Colour Palette**

The design primarily uses:

Purple – Primary action colour
White – Main background
Light Lavender – Secondary background
Dark Navy/Blue – Text
Green – Positive information such as FREE shipping
Soft Grey – Secondary text and borders

Purple is used especially for important actions such as:

Add to Cart → Proceed to Checkout → Continue → Place Order

**🔤 Typography**

The interface uses a modern sans-serif typography style.

Important information such as:

Product names
Prices
Section headings
Buttons

uses larger or bolder text, while descriptions and secondary information use lighter typography.

**📐 Layout**

The design uses:

Rounded cards
Consistent spacing
Clear alignment
Large touch-friendly buttons
Simple navigation
Card-based product presentation

This gives the application a clean and modern e-commerce appearance.

**🖼️ Product Presentation**

Large product images are used to make products visually attractive.

The product cards contain:

Image → Product Name → Price

This allows users to quickly scan products.

**📱 Mobile-First Design**

The screens are designed around a smartphone interface, making the shopping journey suitable for mobile users.
